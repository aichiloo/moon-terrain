# v0.1.0 · 七类月面地形浏览样板

以真实 LROC DEM 为基础的七类地形与局部表面细节展示，包含修正岩石接地后的沟谷版本。

## 完整离线包

下载 `Lunar_Detail_Regions_03.zip`，完整解压后双击 `START_HERE.cmd`；也可在 Edge / Chrome 中打开 `START.html` 或 `index.html`。

包中包含浏览器运行素材、七类地形数据、截图、局部网格、法线与高度图、岩石实例、DEM 副本和来源记录。校验文件为 `Lunar_Detail_Regions_03.sha256`。

## 验证与限制

- 七类地形、28 种版本切换及 43 张贴图已完成浏览器检查。
- 完整 ZIP 及 215 项文件哈希已核对，解压后的离线页面已检查。
- 沟谷继承岩石、碎石和新增布局的静态接地已修订。
- 原始 DEM 间距约 2 米或 3.5 米；2 厘米局部网格与新增细节属于插值和合成增强。
- 未完成 MuJoCo / UE、动态物理、机器狗行走、TASK3 或 VLM 验证。
- 从原始 DEM 完整重建仍依赖未随仓库发布的前序区域库；详见 `docs/PIPELINE.md`。
