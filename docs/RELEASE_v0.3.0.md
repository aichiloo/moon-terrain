# 七类月面地形 · 完整 Unity 工程 v0.3.0

此前的 v0.2.0 提供网页演示。本版本另行提供真正可编辑、可在 Unity 中打开的完整地形工程。

## 下载与打开

下载 `Lunar_Unity_Project_v0.3.0.zip`，完整解压。在 Unity Hub 中添加 `Lunar_Unity_Project/UnityProject`，使用 **Unity 2022.3.62f3c1**。首次导入后，选择 **Lunar Terrain → Open interactive preview**，进入 Game 窗口。

压缩包包含 Assets、全部 .meta、Packages、ProjectSettings、说明和来源记录；七个场景、全部地形与岩石网格、贴图和材质齐全。Library、Temp、Logs、UserSettings 缓存由 Unity 在本机重新生成。

七类地形为平坦岩块区、连续坡面、完整坑区与坑缘、局部凹地、天然坡折、坑外连续起伏、沟谷与两岸。七种材质可在同一场景切换；支持自由观察和预设视角。

## 本次交付修复

- 在 Build Settings 中预先登记七个场景，支持运行时场景切换。
- 编辑器工具主动创建输出目录，统一写到工程内的 Outputs，修复搬迁后缺少目录的问题。
- 加入显式调用的工程检查脚本；普通打开工程时不会自动运行验证或重建。
- 地形网格、已保存场景、岩石与贴图保留原始工程文件内容。

## 验证

在不同于原工程的新目录，使用 Unity 2022.3.62f3c1 重新导入；检查七个场景的地形网格、岩石、材质、纹理和相机引用，进入实际 Play Mode，切换七个场景并逐一检查七种材质、低机位和俯视近景。保存两张实际相机画面。验证报告在 ZIP 的 Evidence/relocation/ 中，并单独附于本 Release。

ZIP 同名 `.sha256` 文件记录归档 SHA256；下载器会核对哈希并检查 ZIP 的安全路径和 CRC。

## 数据与范围

宏观地形来自 LROC LINNECRATER、SHACKRDGE02、MERSENIUS1，原始网格间距为 2 m 或 3.5 m；近景小起伏、岩石位置和数量含合成处理。2 cm 表示近景建模密度。扫描材质为地面月壤模拟物等外观素材，并非选区现场测量。来源与授权记录随包保留。

本发布验证可编辑工程的资源完整性、场景运行、材质和视角操作，不代表机器人行走、碰撞动力学或正式遮挡实验通过。原网页 v0.2.0 与 v0.1.0 继续保留。
